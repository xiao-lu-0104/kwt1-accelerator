# ICC2初次查看1109布局

用户截图已确认GUI成功打开，标题为`system_1109.nlib:e203_cpu_top.design [write]`。这是当前1109完整系统初始布局。图中青色重复矩形为当前可见宏对象，边界内黑色区域不能单凭截图认定标准单元未放置或已经合法化；须结合显示层级及原生实例placement状态核验。

初次操作：

1. 将鼠标移到版图区域，尝试滚轮缩放；若需要全图，从顶部View菜单寻找适应窗口的缩放选项。具体快捷键以安装版菜单显示为准。
2. 单击一个矩形可选中对象，通过右侧Property Editor查看实例属性。使用顶部箭头选择模式，查看时避免切换到移动或编辑模式。
3. 右侧View Settings的Objects标签控制对象显示，可点击Cell左侧加号展开分类，检查其子类别可见性。不要为了显示标准单元而修改设计数据库；层级Level设置及实际单元位置另行检查。
4. 底部Console标签打开命令区，后续如需只读查询，可在其中执行经确认的Tcl，不必在Script Editor中编辑运行脚本。
5. 在VNC中将布局缩放到完整边界并保留顶部设计标题后截图，标注“1109完整系统初始宏布局/初始几何放置”，不标成已布线版图。宏分布示意SVG和完整ICC2 GUI截图应区分。

后续PG/RC/标准单元合法化优化/CTS/布线继续通过独立脚本及设计副本推进。当前GUI中无信号布线是符合当前阶段的，不需要手工添加连线或拖动宏来制造完成效果。

退出时可通过ICC2的File菜单选择Exit，或在底部Console的ICC2提示符输入`exit`。若只是查看且没有更改设计，遇到保存提示时可选择不保存本次查看过程的修改，首次结果已由运行脚本保存；避免误关闭RealVNC窗口而以为服务器工具进程已退出。重新查看时运行已记录的OpenLayout.tcl入口。

剩余实现阶段为RC/层映射及PG配置、宏和引脚规划复核、标准单元放置合法化/优化、CTS和时钟后优化、信号布线、物理与时序检查及导出。顺利推进一版可查看的带线结果暂按2~5小时安排，属于尚无本轮实测支撑的规划估计；RC资料缺失、拥塞或PG/CTS错误会延长至半天以上。完整签核不在该时间承诺内，107秒的初始放置实测不能外推为全部PR耗时。
