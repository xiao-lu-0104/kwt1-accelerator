# 映射 ICB 的复位 X 悲观传播

2026-11-05，来源为服务器保存候选网表、实际标准单元 Verilog 和门级诊断日志。
该记录解释当前故障并定义下一步验证，不表示验证已经通过。

用户回传 `tpusoc_gate_cone_20261105_QRQvHS` 的只读证据显示：
NBA 触发器对照在第一拍同步复位后，State 已为 000，而 Word 为 0x；
Word[0] 的 D 在该拍之前也是 X。此前“收完两个字才出现故障”的定位只是
对外可见握手失败的位置，遗漏了复位期间已经存在的未知内部状态。

实际连接为：

```text
n155 = (RequestReady & RequestValid) | ~ResetN    // AO1B2V0
n174 = ~n155
n304 = ~(n174 & n173)
n303 = ~((WriteDataReady & WriteDataValid) | n304)
n177 = ~((n337 | n621) & n303)
n623 = ~(ResetN & IcbResponseReady)
n574 = ~n623
n176 = ~(n177 & Word[0])
n552 = (n177 & n574 & n176) | (Word[0] & n176)   // AOA211V1
Word[0] FF.D = n552
```

上述单元的功能段由实际库文件回传，其中 AOA211V1 使用两个 AND 再 OR，
与截图连接一致。ResetN=0 时，依次得到 n155=1、n174=0、n304=1、n303=0、
n177=1、n623=1、n574=0。因此：

```text
D0 = Word[0] & ~Word[0]
```

| 当前 Word[0] | 复位时 D0 |
| --- | --- |
| 0 | 0 |
| 1 | 0 |
| X（四态仿真） | X |

这解释了二态布尔逻辑中的复位清零与门级四态仿真的差异：反相信号重新汇合后，
普通门模型不能保留“两个输入互为反相”这一关系。Word[1] 和 State 先复位成功，
不能帮助 Word[0] 摆脱 X。后续计数、数据分组和状态迁移会受此影响。
现有证据支持复位 X 悲观传播，仍需验证它是否足以解释全部任务失败。

`Server/SharedAsic/PrepareBoot.py` / `RunBoot.sh` 定义如下有明确初始条件的对照：

1. 核对上述九个门及实际 Word[0] 触发器的引用与连接；原网表或连接不匹配就停止。
2. 只给这一位 Q 选择 0 或 1，施加一个复位时钟后永久释放；其他映射寄存器不初始化。
3. 对两个初值均检查真实 D0 为 0，释放后继续两拍复位，Word=00、State=000；
   复位释放时必须已完成初始化释放与检查。
4. 两种初值分别完成隔离 ICB 的首 8 字/2 beat；随后在原候选上跑两种初值的完整 FF1，
   再跑初值 0 的单层编码器。所有严格 X 检查、数值比对、边界和 DMA 计数检查均保留，
   ICB RTL 被动镜像必须无分歧。

该对照不改 RTL、候选或厂商模型，初始化操作早于任务计时。
成功后只能报告“明确二态初始条件下的门级功能验证”，不能将其写成
“全 X 初始状态自然复位通过”，也不建立形式等价、SDF 回标或物理时序结论。

本地已验证生成的转义层级引用、Q 初值施加/释放、复位前检查与后续不再驱动的流程；
使用明确标注的合成单元 fixture，不具有实际厂商模型验证含义。
实际库、原候选及完整任务结果待服务器回传。

服务器后续回传：初值 0/1 均通过隔离 ICB，释放后复位清零检查也通过；
但原候选完整 FF1 在 DMA 读推进到 36 次后再次出现 X。
因此本节推导解释了第一处故障，不能解释全部任务失败。
现在用 `PrepareInventory.py` 批量检查映射寄存器复位后的未知值，
并在明确的全 0、全 1、固定随机初值下作完整功能对照；
所有初始化同样只覆盖一个复位时钟，随后永久释放，完整黄金结果检查保留。

批量对照随后已实际回传：`tpusoc_gate_inventory_20261105_fA7tXq` 中，
19695 个映射 FF 分别采用全 0、全 1、固定随机初态，三项完整 FF1 全部通过，
每项 25344 值、332348 周期；固定随机初态的单层编码器也通过，6336 值、1485712 周期。
所有初值在 7000 ps 释放，无后续强制驱动；274 个被观察控制 FF 无新的 Q-X，
ICB RTL 镜像无分歧，严格 X 与完整黄金结果检查保留。

这建立了指定初始条件下的门级功能证据；只初始化 Word[0] 的参照仍失败。
仍有 256 个非控制 FF 的复位 Q 未知，具体归属尚未查明，不能凭本轮任务通过作全局无影响结论。
工程报告必须保留初始化政策与适用范围，不把本次结果表述为全 X 初态自然复位、
形式等价、SDF 回标或物理签核通过。
