# 基于 E203 的定点 Transformer 编码器加速器：初赛技术报告草稿

状态（2026-11-07）：CPU/内部ICB、加速器及全部SRAM的面积、时序与两任务功耗原始报告已归档；
默认/X活动、外设统计边界和最终复现/数值证据仍需核对，本文件不是最终提交版。
当前统计对象为共享 SRAM 装载配置，不使用旧 DDR/AXI、历史 FPGA 或·



 TSMC22 设想的 PPA 代替本配置结果。
参赛组别为本科生组：第 1–3 项为必做，第 4–7 项按队伍目标全部作为选做推进。
评分口径与仍需补齐的证据见 [本科生组评分与收尾](本科生组评分与收尾.md)。

## 1. 实现与任务对应

本设计以 E203 为控制核，通过 NICE 提交 LOAD、EXEC、STORE 和状态查询命令。
计算部分采用八路 16×16 位乘法、分级加法树和 48 位有符号累加，
配合 Softmax、GELU、残差及 LayerNorm 数值处理单元。
详细指令、数值格式、舍入和饱和规则见 [实现规格](Implementation.md) 与 [数值说明](Precision.md)。

独立 FF1 完成 99×64 输入、64×256 权重及偏置运算，逐行计算并写回全部 99×256 结果。
单头注意力覆盖 Q/K/V、99×99 分数矩阵、Softmax、概率乘 V 和输出投影。
单层编码器依次完成注意力、残差归一化及 FF1/GELU/FF2；十二层连续执行为扩展验证。
本项目硬件从 99×64 编码器输入开始，音频前处理与软件分类头在统计边界外。

## 2. 存储与平台接入

平台 ITCM、DTCM 地址宽度均为 18，容量各 256 KiB。程序位于 ITCM，
加载器与 DMA 使用 DTCM 中的输入、输出、当前层参数及控制区。
TPU 私有 SRAM 为 56 个 RAMSP1024X16，共 112 KiB。
私有 SRAM 与平台共享存储分开统计，不能将其合并称为 TPU 内部容量。

数据路径为：加载器经外部 ICB 写当前层数据至 DTCM，E203 通过 NICE 调度，
DMA 经 NICE/LSU 的 ICB 路径搬入 TPU 私有 SRAM，计算后 DMA 写回 DTCM。
ICB 适配器将 128 位 beat 拆为四个 32 位事务，使用一个 outstanding，并保留反压和错误响应。
参数区只有一份当前层缓冲；本层完成并释放参数区后，才能覆盖装载下一层参数。
没有在任务开始前将十二层权重全部装入共享存储或私有 SRAM。

地址布局、握手和计时实现见 [共享 SRAM 方案](SharedSram.md)。

## 3. 数值与验证方法

软件数值模型使用与 RTL 相同的定点运算顺序、最近值舍入（中点远离零）及饱和规则。
每个任务检查全部有效输出、输出区边界、DMA 字节数和 E203 命令计数。
服务器 RTL 回归覆盖正常值、零值、极值及十二组官方层参数的独立 FF1，共十五项，
另有单层和十二层编码器，总计十七项通过。

共享编码器参数由官方模型参数量化生成；正常 FF1 和边界用例另含合成输入。
现有黄金结果逐值一致不等同于真实语音分类准确率。
历史小样本浮点误差分析单列于数值说明，不将其写成正式评测集成绩；
最终交付还需整理输入、参数来源及对应校验值。

## 5. 综合与时序

采用 SMIC40 TT、1.1 V、25°C；时钟周期 6.666667 ns，
setup/hold uncertainty 分别为 0.2/0.1 ns，约束前后未放宽。

## 6. 门级功能及复位条件

采用原候选网表、真实标准单元模型和厂商私有 SRAM 功能模型；
CPU、LSU、TCM 控制器使用竞赛平台原 RTL。
在全部 19695 个映射 FF 的全 0、全 1、固定随机初态下，完整 FF1 均通过；
固定随机初态的单层编码器通过，周期与前表一致。
274 个控制 FF 的观察器未记录新的 Q-X，ICB RTL 镜像无分歧。

这些初值只施加一个复位时钟，7000 ps 时已永久释放，任务期间无后续强制驱动。
原全 X 初态存在复位 X 悲观传播，只初始化 Word[0] 的参照仍失败。
因此本报告结论限定为指定二态初态下的门级功能通过，
不宣称全 X 初态自然复位、形式等价或 SDF 仿真通过。
仍有 256 个非控制 FF 的复位 Q 未知，其具体归属尚未核实。
详细过程和适用范围见 [复位说明](GateReset.md)。
