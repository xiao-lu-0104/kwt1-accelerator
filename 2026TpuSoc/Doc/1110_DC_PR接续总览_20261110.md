## 7. 已踩过的坑及纠正方法

1. **SDC写出精度**：6.666667ns可能序列化成6.66667ns，差3e-6ns。旧容差1e-6误报预算改变。先以Decimal核对原预算到序列化值确是打印舍入，保留原SDC SHA，再核原生读入值；不要直接改时钟放松预算。
2. **check_pg_connectivity参数**：`-check_std_cell_pins true`非法，实际枚举one/all/none，完整检查用all：

   ```tcl
   check_pg_connectivity -check_macro_pins all -check_std_cell_pins all
   ```

3. **缺scan DEF导致PLACE-042**：本轮功能设计未做扫描链。1109实际验证安装版支持以下设置后完成布局；1110先查选项存在，若以后做DFT应输入真实scan DEF，不伪造：

   ```tcl
   get_app_options place.coarse.continue_on_missing_scandef
   set_app_options -name place.coarse.continue_on_missing_scandef -value true
   ```

4. **先检查后保存会丢长步骤**：PG初次到2400s超时，DRC没结束导致未到save。改成核心动作/宏签名核验后save_block/save_lib/write_def并记录CORE_SAVED，再在独立副本/进程跑检查。每阶段独立检查点，失败接最后成功阶段，勿重跑已成功DC/功耗/RC/PG。
5. **超时不等于EDA崩溃**：StageWatch打STAGE_TIMEOUT、exit124后发SIGTERM，堆栈/Terminated不能单独归因工具bug。心跳仅计时，不能当推进百分比，结合原生日志及进程状态。
6. **长循环开销**：1110 hold恢复v1曾CPU忙且耗时长，逐叶add_to_collection可能开销大；备用FastFreeze以批量filter_collection实现并核等价成员。v1已成功，不为换优化脚本再跑一次。
7. **宏几何不是固定面积等式**：旧LEF82.46×110.945µm，native bbox高度111.1314µm，差0.1864µm，不是已证实单位错误。采用实际bbox检查重叠/边界，记录差异，别改PDK或硬断言DC面积等于物理bbox面积。
8. **FTP421**：曾无登录banner返回too many connected users，不是密码错。Uploader先ConnectionOnly/预检查，421停止，不反复百次重试。无需聊天发送密码。
9. **VNC传输SHA**：先文本编辑器粘完整入口，保存后验SHA。只允许已验证的UTF8 BOM/CRLF/CR/首尾空行规范化，并必须匹配原冻结SHA才新建verified.sh；截断/内容改变拒绝。NormalizeSystemCommand.txt保留完整命令，不改期望SHA绕过。
