## 二、任务 3：SoC 集成（唯一硬缺口）

### 2.1 接入方式（已确认，勿再改）

- 平台：`e203_hbirdv2`，存储总线 O5 出口 **`0x4000_0000`**（256 MB 窗口）
- 通路：`sirv_icb1to8_bus(O5)` → `sirv_gnrl_icb2axi` → `sirv_expl_axi_slv`
- **做法：实现 AXI4 full 从机，替换 `sirv_expl_axi_slv`**
- **不需要写 ICB 从机**（ICB 层由平台转换）
- 地址映射已与竞赛版 `e203_subsys_mems.v` L129–156 逐行核对一致

### 2.2 待办分解

- [ ] **encoder MMIO 寄存器块**
      CTRL / STATUS / CYCLES 等控制寄存器；参数走 `kwt_param_stream`（两条 32-bit 写拼一条 64-bit 记录）
- [ ] **AXI4 full 从机**
      现有 `kwt_axi_slave.v` 是 AXI4-Lite，需支持 `arlen`/`awlen` 突发与 `rlast`/`wlast`
- [ ] **接 `kwt_encoder_12`**
      注意 `kwt_axi_top.v` 里例化的是旧核 `kwt_top`，要换成 `kwt_encoder_12`
- [ ] **C 驱动**
      参数下发 → 启动 → 轮询 done → 读回 99×64 输出
- [ ] **SoC 仿真跑通**
      至少做到：寄存器读写正确 + 一次完整前向输出与 RTL 仿真逐位一致

### 2.3 参数装载的计时影响（写文档时要用）

45,384 条参数记录，每条 2 次 32-bit 写 = **90,768 次总线写**。
按 ICB 单拍 + AXI 握手估约 **18–36 万拍 ≈ 1.2–2.4 ms**，占 21.6 ms 的 5–11%。

> 若后续要做吞吐数字，这部分必须计入赛题计时口径。

## 三、两个容易漏掉扣分的点

### 3.1 面积报告口径必须含接口逻辑

赛题 L243–246：

> 面积指标为新增加速器、**接口逻辑**及内部 SRAM 宏面积之和，上限 2.25 mm²……
> 复用的 E203、512 KB 共享 SRAM 及固定总线和外设不计入

现状：**0.9812 mm² 是纯 encoder，不含 AXI/MMIO 接口**。

- [ ] 加完接口逻辑后**用集成后的顶层重跑一次综合**
- 预计接口逻辑 0.02–0.05 mm²，预算无压力（当前余量 56%），但口径必须对

### 3.2 任务 1 / 任务 2 需要"可指认的独立 RTL + testbench"

任务 2 原文（L133–137）：

> 实现 99×64 输入与 64×256 权重相乘并加偏置，输出 99×256……支持依次更换 12 层编码器的对应参数

我们的实现嵌在紧凑层内部复用，**功能满足但评审时难以一眼对上任务清单**。

- [ ] `kwt_task1_mac.v` —— 包 `kwt_mac16x4` + `kwt_requant`（64 点积 + 偏置 + 数值转换），配独立 tb
- [ ] `kwt_task2_ffn.v` —— 包紧凑层 FFN 路径（99×64 × 64×256 → 99×256，支持换层参数），配独立 tb

纯包装工作，1 天以内。
