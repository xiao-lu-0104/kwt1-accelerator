## 2. 模型事实（已核实）

- `d_model=64`, `mlp_dim=256`, `heads=1`, `layers=12`, PostNorm, GELU
- 前向：`(B,16000) → SpeechFeatures → (B,98,40) → patch(40,1) → 98 tokens + 1 class token = 99×64 → 12×Encoder → (B,64) → Linear(64,12)`
- 总参数 607,308；Transformer 主体 606,528
- 每层参数 49,408：QKV 12,288 + O 4,096 + FFN 32,768 + LN 256
- 12 层 ↔ 12 个类别（评分抽取规则：本科覆盖 12 层，研究生覆盖 12 类）

### 参数量/带宽推算
| 数值格式 | 全模型权重 | 每层 | 512 KB SRAM 可装 |
|---|---|---|---|
| FP16 | 1.19 MB | 96.5 KB | 5 层 |
| INT8 | 593 KB | 48.3 KB | 10 层 |
| INT4 + INT8 混合 | ~350 KB | ~29 KB | 全部 12 层 |

> **这是核心架构约束**：权重全量装载次数直接计入任务耗时（规则见赛题 3 条），
> 所以"能否一次装完 12 层"是一个可量化的收益点，也是创新点素材。

### 计算量
每层 6.12M MAC，12 层 73.4M MAC。
- 64 MAC/cyc @70% → 1.64M cyc → 10.9 ms
- 128 MAC/cyc @70% → 819K cyc → 5.5 ms
- 256 MAC/cyc @70% → 410K cyc → 2.7 ms
（150 MHz）

## 4. 待决策（需要队内拍板）

| # | 决策 | 选项 | 初判 |
|---|---|---|---|
| D1 | AI Engine 接入方式 | System Bus / NICE | **System Bus**（大批量搬运；NICE 适合指令级小算子） |
| D2 | 数值格式 | W8A8 / W8A16 / W4A8 混合 | 先实验，用数据定。优先 W8A8 |
| D3 | 内部 SRAM 容量 | 0 / 8 KB / 16 KB / 32 KB / 64 KB | 先用 16b×4096 宏拼，等面积数据再定 |
| D4 | 并行度 | 64 / 128 / 256 MAC | 128 MAC 起步，面积允许再加 |
| D5 | Softmax 实现 | 行内全量 / 在线（flash 式）流式 | 行内 99 点，两遍扫描（max → exp-sum → 归一） |
| D6 | 激活存储策略 | 全驻留 / 行级流式 | 行级流式省 SRAM，但增加控制复杂度 |
