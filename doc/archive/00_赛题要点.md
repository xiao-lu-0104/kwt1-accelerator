## 1. 题目一句话

用 **KWT-1**（ARM Keyword Transformer 最小型号）开源预训练权重，在 **E203 RISC-V SoC** 平台上设计**数字前端加速器**，完成端侧离线语音指令识别，并做综合、精度/吞吐/功耗/面积评测。

- 输入：1 s / 16 kHz 单声道语音
- 特征：98×40 MFCC → 输入投影 + class token + 位置编码 → **99×64**
- 模型：**12 层编码器**，d_model=64，**1 注意力头**，FFN 64→256→64，GELU，**PostNorm**
- 输出：12 类（yes/no/up/down/left/right/on/off/stop/go + 静音 + 其他）
- 分类头由组委会软件执行，不计入硬件吞吐
- batch=1，无变长输入、无因果掩码

## 2. 模型与数据来源

| 项目 | 指定内容 |
|---|---|
| 代码/权重 | `ARM-software/keyword-transformer`，commit **237e4097**，`models_data_v2_12_labels/kwt1`，`best_weights` |
| 运行模式 | 仅推理；关闭训练/随机增强/Dropout |
| 数据集 | Google Speech Commands **V2**（`speech_commands_v0.02`），队伍自行下载 |
| 划分 | 训练集：无梯度标定；验证集：功能/精度调试；**测试集不得用于调参** |
| 统一评测集 | 组委会选 **600 条**样本，评测后公布清单 |
| 硬件输入 | 队伍离线生成（音频规范化、MFCC、投影、位置编码），硬件只接收 99×64 |

## 3. 硬件平台（组委会给定）

- 芯来 **E203** 开源 RISC-V + 配套软件环境；总线/外设用组委会平台工程
- AI Engine 接入方式**二选一**：System Bus **或** NICE Interface
- 系统共享 **SRAM 512 KB**（不设 DDR/外部存储控制器；权重无需全驻留）
- 加速器内部存储只能用指定宏：**16b×128 / 16b×1024 / 16b×4096**（单口或双口）
- 系统时钟 **150 MHz**（统一工作频率 + 综合时序目标），SoC 提供 PLL
- 常开域：RTC / WatchDog / PMU / LCLKGEN，低速时钟 32.768 kHz
- 参数加载：分层装载；组委会提供**参数加载仿真环境**，通过平台已有接口写共享 SRAM

## 5. 硬性约束

1. **RTL 语言**：Verilog / SystemVerilog，可综合；不含布局布线/物理验证/流片
2. **不得改模型**：不重训/微调/蒸馏；不改层数、维度、基本运算结构；允许无梯度标定 + 数值格式转换
3. **数值自由**：定点/浮点/混合、位宽、scale、舍入/饱和、MAC 结构、并行度、流水线、缓存、非线性近似（GELU/Softmax/LN 可查表/分段/迭代）
4. **必做计算不得由 CPU 软件或测试平台代算**
5. **面积上限 2.25 mm²**（1.5×1.5），统计范围 = 加速器 + 接口逻辑 + 内部 SRAM 宏；E203/512 KB/固定总线外设不计入但需单列
6. **精度门槛**
   - 本科：归一化 RMSE ≤ **3%**（12 层分别汇总全部评测样本，取最大值；分母下限 1e-8；误差 0 得 10 分，每 +0.3 pp 扣 1 分）
   - 研究生：Top-1 准确率相对统一浮点参考下降 ≤ **2 pp**（达标 10 分，每降 0.2 pp 扣 1 分）
7. **RTL 必须与提交的软件数值模型逐位一致**（评审复核；不一致视为功能不通过）
8. **全部解码结果须为有限值**
9. 提交全部设计来源与引用说明；不得预存答案、不得把必做计算挪到 IO 适配脚本

## 7. 性能测量规则（重要）

- 本科 1 个任务 = 1 次前馈线性计算并写回；研究生 1 个任务 = 1 次十二层编码器计算并写回
- 计时**从输入与参数开始装载**到结果全部写回；**任务前清空数据与参数缓存**
- **参数装载、总线等待、E203 调度时间全部计入**；任务间复位不计入
- 组委会抽 **12 个任务**（本科覆盖 12 层参数；研究生覆盖 12 个类别）
- 功耗：统一库/工艺角/负载/时钟/互连条件，用同一计时窗口 SAIF/VCD 综合估算；统计 E203 + 加速器 + 互连 + SRAM；未标注电路不得按零活动、未建模 SRAM 不得按零功耗
- 单任务能耗 = 平均功耗 × 总运行时间 / 完成任务数
