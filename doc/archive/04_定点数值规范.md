# 定点数值规范（RTL / 软件模型共同基准）

> 状态：v0.1，待 RTL 实现后回填实测值
> 原则：**软件数值模型必须与 RTL 逐位一致**（赛题硬要求）。本文所有舍入/饱和/近似规则都是唯一权威定义。

## 1. 数据格式

| 张量 | 格式 | 说明 |
|---|---|---|
| 激活 `q_x` | int8，对称 | `x = q_x · S` |
| 权重 `q_w` | **int4**，对称，**per-output-channel** | `w = q_w · S_w[c]` |
| 偏置 | int32 | 预缩放：`b_q[c] = round(b[c] / (S_x·S_w[c]))` |
| 累加 `acc` | int32 | 64 项或 256 项 MAC |
| softmax 概率 | int8，**独立 scale** | absmax≈0.167（99.9 分位标定） |
| LN 统计量 | int32 / Q16 | mean、var 累加 |

### 量化范围
- int8 对称：`[-127, 127]`（不使用 -128）
- int4 对称：`[-7, 7]`（不使用 -8）
- 饱和：超出即 clip 到端点（RTL 用 saturating add 后接 clip）

## 2. 矩阵乘 + requant

```
acc[c] = Σ_i q_x[i] · q_w[i,c]          (int32, i = 0..63 或 0..255)
acc_b  = acc[c] + b_q[c]                (int32, 饱和)
M[c]   = S_x · S_w[c] / S_y             (实值)
M_int[c] = round(M[c] · 2^31)           (int32 定点乘数, Q1.31)
q_y[c] = sat8( (acc_b · M_int[c] + (1 << (31-1))) >> 31 )
```

- **舍入**：round half up（加半个 LSB 再算术右移），与 Python `(a + (1<<(n-1))) >> n` 一致
- **饱和**：结果 clip 到 `[-127, 127]`
- 若 `M[c] ≥ 1`（少见），换用更小的 `2^n` 并相应调整移位量，保持 `M_int < 2^31`
- 累加不会溢出：最坏 `64 × 127 × 7 = 56,896`，远小于 `2^31`

## 3. 残差相加

`out1 = x + attn_proj`：两个 int8 张量 scale 不同（`S_x` vs `S_p`）。

方案：**int16 中间域**
```
S_r = max(S_x, S_p)                     (残差域 scale)
q_x16 = q_x · (S_x/S_r)                 (定点乘法，int16)
q_p16 = q_p · (S_p/S_r)
q_r16 = q_x16 + q_p16                   (int16, 饱和)
```
- 若 `S_x/S_r` 设计成 2 的幂，则退化为纯移位，**推荐在标定时强制此约束**
- LN 直接吃 int16，输出 int8

## 4. LayerNorm

输入 `q_r16`（int16，scale `S_r`），输出 int8（scale `S_ln`）。

```
sum   = Σ_{i=0..63} q_r16[i]                       (int32)
mean  = sum / 64                                   (int32, 截断)
d[i]  = q_r16[i] - mean                            (int16)
var   = Σ d[i]^2 / 64                              (int32)
inv   = rsqrt(var + eps_q)                         (Q16.16)
y[i]  = (d[i] · inv) >> 16                         (int32)
y[i]  = y[i] · gamma_q[i] + beta_q[i]              (int32 → int8 requant)
```

实现要点：
- `rsqrt`：LUT 256 项取初值 + **1 次牛顿迭代** `y = y·(3 - v·y²)/2`
- `gamma_q`、`beta_q`：以 `S_ln` 为基准预量化为 int16/int32
- `eps_q`：`1e-6 / S_r²` 折算到整型域

## 5. GELU

输入 int8（scale `S_g`），输出 int8（scale `S_h`）。

- **查表 + 线性插值**：x ∈ [-6, 6] 映射到 256 个表项（int16），步长 12/256
- `|x| > 6`：`y = x`（正）或 `0`（负）
- 表项内容 = `gelu(x_real) / S_h`，预计算并 floor
- 插值用 int32 乘加，最后 `>> 8` 并饱和

> 注意：**官方实现是 erf 精确版，不是 tanh 近似**（已实测确认）。LUT 必须按 erf 版生成。

## 6. Softmax（99 点，单行）

```
s[j]    = QK^T[j] requant 到 int8 (scale S_s)         或保持 int16 提高精度
m       = max_j s[j]
e[j]    = EXP_LUT[s[j] - m]                           (int8/int16, 0..255)
sum     = Σ e[j]                                      (int32)
p[j]    = (e[j] · 2^15) / sum                         (int32 除法 → int8 概率)
```

- `EXP_LUT`：256 项，覆盖 `x ∈ [-16, 0]`，`e = round(exp(x) · 255)`（或用 `exp2` 基 + 移位）
- 除法器：int32 / int32，1 拍或迭代式（99 次）
- 概率 scale = `1/127`（可标定为 0.167/127 以提高分辨率）

## 7. 各张量 scale 标定顺序

标定集：**training 划分**（不得用 testing），600 条验证集仅用于精度评测。

顺序：
1. 浮点前向，记录每个 tap 的 absmax
2. 激活 scale 取 absmax（或 99.9 分位）
3. 权重 per-channel scale = 每输出通道 absmax / 7
4. 派生：bias 预缩放、M_int、gamma/beta 预量化、LUT 生成
5. 生成 `scales.json` + `weights.bin` + `lut.bin`

## 8. 参数二进制布局（待定稿）

每层固定 6 个矩阵：q(64×64)、k(64×64)、v(64×64)、o(64×64)、ff1(64×256)、ff2(256×64)。
- int4 按**输出通道优先**打包：同一输出通道的 64 个权重连续（32 字节），便于 RTL 顺序读取
- 各矩阵前放置该矩阵的 per-channel scale 表（int16 或 fp16，待定）
- 层间按 `[q][k][v][o][ff1][ff2]` 顺序拼接

## 9. 位一致验证方法

1. Python `fixed_sim.py`（全整数运算）产生逐层 int8/int16 输出
2. RTL 仿真输出与之**逐位比较**（`===`，非容差比较）
3. 任何不一致都视为 bug，不允许用容差掩盖
