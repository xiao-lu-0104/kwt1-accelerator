# 数值方案实验计划

> 目标：在满足"研究生组 Top-1 相对浮点参考下降 ≤ 2 pp"的前提下，找到**面积/带宽/吞吐最优**的数值格式。
> 状态：待 P0 实验填充数据。

## 1. 评价口径（严格按赛题）

- 浮点参考 = 官方 TF 权重 + 官方前向（本仓库 `tools/export_reference.py` 产出的 `logits`）
- 主指标：Top-1 准确率绝对差（pp）；同时记录 logits 的余弦相似度、相对 L2 误差
- 次级指标（本科口径，也用于研究生自查）：每层输出的归一化 RMSE `rms(err)/rms(ref)`，分母下限 1e-8
- 数据：validation 划分（不得用 testing 划分调参）

## 2. 必须回答的问题

| # | 问题 | 影响 |
|---|---|---|
| Q1 | 权重 int8 per-channel 是否足够？ | 权重带宽、SRAM 容量 |
| Q2 | 激活 int8 是否足够，还是需要 int16/混合？ | 内部 SRAM、MAC 位宽 |
| Q3 | 哪些层/张量对量化最敏感？（LN 输出 / softmax 概率 / GELU 后） | 混合精度分配 |
| Q4 | 权重 int4（per-channel，group size 32/64）能否守住 2 pp？ | 参数装载时间（直接进任务耗时） |
| Q5 | LN 的 rsqrt 用哪种近似、GELU 用哪种近似、softmax 的 exp 用哪种基？ | 逻辑面积、精度 |
| Q6 | 累加位宽：int32 够吗？是否存在溢出风险？ | MAC 阵列面积 |

## 3. 实验矩阵

### E1 权重-only 量化
- W8 per-tensor（对称，absmax）
- W8 per-channel（对称，按输出通道）
- W4 per-channel（group = 64 / 32）
- 激活保持 float32

### E2 权重 + 激活量化
- W8A8 per-tensor
- W8A8 per-channel（权重）+ per-tensor（激活，按张量 absmax 或 percentile）
- W4A8
- W8A16（仅 LN 输出、softmax 概率用 int16）

### E3 非线性近似
- GELU: 精确 erf / tanh 近似 / 分段线性 LUT（256 项）
- Softmax: exp2 基 LUT + 定点除法 / 迭代归一
- LayerNorm: rsqrt 牛顿迭代（2 次） / LUT 初值
- 各组合对最终精度的影响

### E4 边界与溢出
- 统计每个量化点的真实最大值分布（percentile 99.9 / 99.99 / max）
- 校验 int32 累加不会溢出（最坏情况：64 × 127 × 127 = 1.03M，远小于 2^31，安全）
- 校验中间激活在 int8 动态范围下的饱和比例（目标 < 0.01%）

## 4. 输出物

- 权重 absmax：QKV 0.17–0.27，FFN1 0.29–0.42，FFN2 0.26–0.53

## 6. 实验结果（2026-10-17，validation 前 200 条）

浮点参考：官方 TF 权重 + 官方前向，**acc = 97.0%**（与官方报告 97.7% 同量级）。
NumPy 实现与 TF 对齐：12 层 norm_rmse ≤ 7.8e-7，logits max_abs_err 2.9e-6，预测一致率 100%。

| 配置 | 准确率 | 相对 float | 预测一致率 | logits 相对 L2 |
|---|---|---|---|---|
| W8 per-channel / A float | 97.0% | 0.00 pp | 100% | 8.95e-3 |
| **W8 pc / A8 / softmax int8** | **97.0%** | **0.00 pp** | **99%** | **5.10e-2** |
| W4 pc g32 / A8 | 98.0% | −1.00 pp | 98% | 1.22e-1 |
| W4 pc g64 / A8 | 98.0% | −1.00 pp | 98% | 1.30e-1 |

### 结论
1. **W8 per-channel 权重 + int8 激活满足精度要求，且零准确率损失**。
2. **4-bit 权重（group 32/64）也没有可测量的准确率损失**，全模型权重从 593 KB 降到 297 KB。
3. 概率（softmax 输出）必须使用独立标定：其 absmax 约 0.167（99.9 分位），若错误地套用激活 scale 会被整体量化为 0（这是第一版实验崩溃的原因）。
4. 首层输入 `x` 有长尾：absmax 13.8 / absmean 1.57，int8 下 5.7% 的值归零，但 LN 会吸收，不影响精度。
5. 200 条样本下 1 pp 属于统计噪声，需 600 条复核。

### 关键架构含义
| 方案 | 每层权重 | 12 层合计 | 512 KB SRAM 可驻留 | 参数装载次数 |
|---|---|---|---|---|
| W8 | 49.5 KB | 594 KB | ❌ 装不下全部 | ≥2 次 |
| W4 g32 | 24.7 KB + 0.25 KB scale | 300 KB | ✅ 全部驻留 | 1 次 |

> 由于"参数装载计入任务耗时"，W4 可以直接减少 ~50% 的装载时间。
> 代价：int4 解包逻辑 + per-group scale 存储，需要额外面积与时序评估。
