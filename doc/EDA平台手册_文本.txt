NICT 集成电路设计培训部 EDA 平台_用户登录使用手册                             
                                                                                             
一、EDA 平台简介                                                                                      
1、EDA 平台部署远端的EDA 设计环境，用户日常的IC 设计和培训工作主要是通过图形
化客户端 VNC-viewer（Windows 平台下的软件）远程登录到Linux 服务器中操作完成，可通
过下列方式进行登录：                                                                                          
1.1 电脑只要接入到internet 互联网中，均可通过电脑中VNC 客户端进行登录；                               
1.2 EDA 服务器 ic*h22.nicu.cn:159** (*部分需根据帐号分配内容进行填写)。                                                                                                         
2、芯片设计所需的EDA 工具软件统一安装在各服务器的/eda 目录下，普通用户可以访问
和执行，无法修改和删除。EDA 工具的新增和版本更新需由服务器管理员通过root 管理员
账号登录后操作完成。                                                                                                                                                                                               
3、 用户登录后的home 目录位于/home 下，通常采用基于csh/tcsh 的 SHELL。用户个人
的环境变量设置信息均保存在该目录下的.cshrc 隐藏文件中，用户可根据需要进行适当修
改。默认的 EDA 工具使用环境已经配置好，不需要进修改。                                     
4、默认 home 位置为 storage1/2026contest/xxxxx。每组的用户目录均相互独立，互相之
间无权限访问。                                                         
5、Linux 系统下不支持windows 平台中常用的 RAR 数据格式，可支持的压缩包的数据格
式为 zip/tar/tar.gz 等，用户通过FTP 上传的文件，推荐使用zip 压缩包或 tar.gz 格式的文
件。                                                                                                     
6、Linux 系统下文件和文件夹的名称区分大小写，且应避免使用空格、中文和特殊符号
等，请格外留意!（可以使用下杠“_”和中杠“-”代替空格等特殊字符） 。 
                                                                                                                                                                                 
二、VNC 远程登录操作                                                                                    
1、用户 windows 电脑中需提前安装好VNC-viewer 客户端软件，并填写域名及对应的VNC
端口信息后即可通过VNC 登录密码进行登录。                                                                                                                                                                                       
1.1 VNC-viewer 客户端属于官方免费软件，可以不用注册账号即可安装使用。推荐使
用新版本。目前最新VNC 版本为 6.21.406，用户可直接安装后使用。

改，且要求首次登录后也需要进行修改。  
三、EDA 工具的使用                                                                         
 1、通过 VNC 登录到 EDA 服务器后，可以双击桌面terminal 图标，或在桌面右击，并
选择 terminal 按键，弹出命令行界面，直接输入工具的启动命令即可使用EDA 工具。                          
常用的命令比如verdi/pt_shell/fm_shell/dc_shell 等。                                                   
四、VNC 界面画质调整                                                                                      
1、VNC 界面画质可以根据需要调整成中/低画质，画质设置的越低，操作越流畅。                                              
由于 Hight 画质占用网络带宽巨大，且画质也无法直观地得到改善，禁止使用该选项。                           
2、设置画质的方法是：登录 VNC 后，按键盘 F8,点击“Properties”进入设置界面。

五、FTP 工具的使用 
1、每一组的用户，拥有 FTP 上传数据到 Linux 服务器的权限,无法下载数据。 
2、竞赛过程中可使用专用的FTP 客户端工具向服务器内上传各组自己的相关资源，使
用 FTP 工具上传至的具体目标路径为：各队伍账号 home 目录下 Desktop 桌面文件夹内。  
3、FTP 工具只可用于向服务器内上传竞赛相关的代码文档等，各队伍的存储空间以参
赛队全体队员为第一责任人，请勿上传与竞赛无关的内容、或是上传违反国家法律的违法
内容，一经发现则取消相应的竞赛资格。    
3、FTP 工具请自行准备。 
4、用户登录 VNC 后，可通过 yppasswd 命令修改 Linux 底层密码，需按提示输入旧密
码，再输入新密码，按N 不创建只读密码。 
该 Linux 底层密码也就是锁屏后解锁的密码。FTP 使用的就是用户的Linux 底层密码；
FTP 的密码需要使用修改后的新密码才能登录。 
5、FTP 使用案例说明 : 初次连接 FTP 服务器时，信息的相关配置在站点-站点管理器
中进行更改。首先在站点中选择站点服务器打开（或按F4 打开） ，随后选择左侧列表中已
经预配置好的站点，在用户名和密码两格中填入本组的用户名与密码，用户名和密码为
Linux 底层用户和密码，并非 VNC 登录窗口的密码（初始密码设置相同） 。再先点击应用进
行保存，最后点击连接即可，如下图所示：
