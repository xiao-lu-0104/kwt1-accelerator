### 本轮额外修复的数值 bug

- `gmul = y_q8 * gamma_q` 只有 32 位，`gamma_q` 升到 ~1e4 后可能溢出 → 全部中间量改 64 位
- `tb_kwt_layernorm.v` 硬编码 `eps_q = 1`，而 Python/硬件用 0 → 导致 LN 单独 TB 出现 5 个 ±1 错误（已对齐为 0）

### 剩余瓶颈（下一步可做）

| 项 | 周期/层 | 占比 | 思路 |
|---|---|---|---|
| FFN2 计算（IN=256，SEGS=4） | 25344 | 24 % | 给 FFN2 的 K 维也加第二组 64 点积（SEGS 减半） |
| AV 计算（IN=128，SEGS=2） | 6341 | 6 % | 同上 |
| softmax（25 批 × 298 拍） | 7450 | 7 % | 8 行并行，或前两遍 2 路扫描 |
| FSM 切换 / softmax 载入 | ~24000 | 23 % | 双缓冲、score_buf 4 宽载入 |

> 注：已尝试过 softmax 前两遍 2 路并行，因舍入链变化导致 334 处 ±1 偏差，已回退。
> 如需再做，必须先把 `inv = (127<<20)/total` 改成四舍五入形式并重标定参考。

## 5. 顶层数据通路

```
MFCC 98×40 int8 (s_mfcc)
   │
   ├─ patch_proj  40→64, int4 权重, int8 激活
   │     └─ 补零到 64 通道，复用 kwt_gemm_engine
   │
   ├─ + class token (1×64) + pos_emb (99×64)，均为 s_x 域常数
   │     └─ x_q[t] = sat8(patch_q[t] + pos_q[t])  (t≥1)
   │        x_q[0] = cls_q + pos_q[0]
   │
   ├─ kwt_encoder_12 (12 层, s_x → s_out)
   │     └─ 单份 kwt_encoder_layer 硬件 + 12 次参数 ROM 扫描切换
   │
   ├─ head  64→12 (补零到 16), int4 权重
   │     └─ 仅取 token 0（class token）
   │
   └─ argmax over 12 logits → 4 bit 类别
```

## 6. 参数 ROM 布局

`kwt_encoder_12` 通过 `ld_sel` 分 13 段扫描参数，外部 ROM 按 `{cur_layer, ld_sel, ld_addr}` 寻址：

| ld_sel | 内容 | 长度 |
|---|---|---|
| 0..3 | Q/K/V/O 权重（int4） | 4096 nibble 各 |
| 4..5 | FFN1/FFN2 权重（int4） | 16384 nibble 各 |
| 6 | Q/K/V 乘数（地址 bit[7:6] 选 Q/K/V） | 192 |
| 7 | O 的 bias + 乘数 | 64 |
| 8 | FFN1 的 bias + 乘数 | 256 |
| 9 | FFN2 的 bias + 乘数 | 64 |
| 10..11 | LN1 / LN2 的 gamma_q + beta_q | 64 各 |
| 12 | 层常量（m_score, m_ctx, ma1, mb1, ma2, mb2） | 6 |

**这一机制即赛题 Task 2 要求的"12 层参数切换"验证点。**

## 9. 复现命令

```powershell
cd e:\chipdesign

# 1. 生成标定与全部测试向量
.\.venv\Scripts\python.exe tools\calibrate.py
.\.venv\Scripts\python.exe tools\gen_attention_vectors.py
.\.venv\Scripts\python.exe tools\gen_encoder_vectors.py
.\.venv\Scripts\python.exe tools\gen_encoder12_vectors.py
.\.venv\Scripts\python.exe tools\gen_top_vectors.py

# 2. 编译 RTL
cd sim
xvlog -sv ..\rtl\kwt_dot64.v ..\rtl\kwt_gemm4.v ..\rtl\kwt_gemm_engine.v `
  ..\rtl\kwt_exp_lut.v ..\rtl\kwt_softmax.v ..\rtl\kwt_rsqrt_lut.v `
  ..\rtl\kwt_layernorm.v ..\rtl\kwt_gelu_lut.v ..\rtl\kwt_gelu.v `
  ..\rtl\kwt_attn_qkv.v ..\rtl\kwt_attn_score.v ..\rtl\kwt_attn_av.v `
  ..\rtl\kwt_attention.v ..\rtl\kwt_align_add.v ..\rtl\kwt_encoder_layer.v `
  ..\rtl\kwt_encoder_12.v ..\rtl\kwt_top.v ..\tb\tb_kwt_top.v

# 3. 仿真
xelab tb_kwt_top -s top_snap --debug typical
xsim top_snap -R
```

> 注意：xsim 每次运行后会残留文件锁，重跑前需
> `Get-Process | ?{$_.ProcessName -like '*xsim*'} | Stop-Process -Force` 并删除 `xsim.dir/<snap>`。
