# 定点数值方案与实测结果（定稿）

> 日期：2026-10-17
> 结论：**W4 权重 + int8 激活 的完整 12 层定点实现，600 条评测集准确率下降 0.67 pp**，门槛为 2 pp。

## 1. 最终格式

| 张量 | 格式 | scale | 说明 |
|---|---|---|---|
| 权重 | **int4**，per-output-channel，范围 [-7,7] | `S_w[c] = absmax(w[:,c])/7` | 全模型 300 KB |
| block 输入 `x` | int8 | 全局标定 0.1086 | |
| Q / K / V | int8，**各自独立 scale** | 0.0249 / 0.0790 / 0.0358 | 三者动态范围差 3 倍，共用会毁掉 Q |
| score | int16 | 1/256 | delta 最大 21，int16 足够 |
| softmax 概率 | uint8 (0..127) | 1/127 | 四舍五入，否则总和只有 88/127 |
| ctx | int8 | 0.0340 | |
| o（O 投影输出） | int8 | 0.0248 | |
| 残差 r1/r2 | int16 | min(两侧 scale) | Q10 定点对齐 |
| LN 输出 | int8 | 0.0418 | |
| GELU 输入 `hin` | int8 | 0.0430 | **与输出分开标定** |
| GELU 输出 | int8 | 0.0347 | |
| f（FFN2 输出） | int8 | 0.0401 | |
| block 输出 | int8 | 0.0448 | |

## 2. 实测结果（600 条 validation）

| 模型 | 准确率 | 相对 float | 预测一致率 |
|---|---|---|---|
| 浮点参考（官方 TF） | 97.33% | — | — |
| **完整定点 12 层** | **96.67%** | **−0.67 pp** | **98.17%** |

赛题门槛：Top-1 相对浮点参考下降 ≤ 2 pp。**余量 1.33 pp**。

## 3. 过程中踩到的四个坑（都已修复）

### 坑 1：softmax 向下取整
`p = (e·inv) >> 20` 使 99 个概率的**总和只有 88.7/127（损失 30%）**，AV 输出系统性偏低。
修复：改为四舍五入 `(e·inv + 2^19) >> 20`，总和恢复 126。

### 坑 2：GELU 输入输出共用 scale
GELU 对负半轴压缩，输入范围显著大于输出；共用 scale 导致输入侧大量饱和。
修复：`hin` 与 `h` 分别标定。

### 坑 3：残差对齐用整数比例
`s_x/s_o = 4.39` 被 `round` 成 4，残差里的 x 分量直接少 9%。
修复：Q10 定点乘数 `(a·ma + b·mb) >> 10`，硬件为两个乘法器加一个加法器。

### 坑 4（最致命）：层间输入 scale 不一致
第一层输入 scale 是 `s_x=0.1086`，之后每层输入是 `s_out=0.0448`，但残差对齐**一直按 s_x 计算**，导致第 2 层起残差分量放大 2.4 倍。
修复：每层构造时传入自己的 `s_in`。
> 修复前后：58.5% → 96.5%。**这是单点最大的 bug**。

### 坑 5：Q/K/V 共用 scale
Q 的最大值 1.7、K 是 10.0，共用由 K 决定的 scale 后 Q 只剩 22 个量化级。
修复：各自独立标定。

## 4. 消融验证（60 条）

从浮点开始逐个打开量化点：`float / w4 / x8 / qkv8 / score16 / prob8 / ctx8 / o8 / ln8 / h8 / f8 / all`
—— **全部配置均为 96.67%**。

说明上述定点格式的每一环都没有额外损失，此前的崩溃全部来自实现 bug，而不是量化策略本身。

## 5. 硬件含义

| 项 | 数值 |
|---|---|
| 权重总量 | 12 层 × 24.7 KB ≈ **300 KB**（可一次驻留 512 KB 共享 SRAM） |
