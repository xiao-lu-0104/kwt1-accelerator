# 注意力模块微架构（任务 4）

> 状态：设计定稿，待 RTL 实现
> 前置：`kwt_gemm_engine` / `kwt_softmax` / `kwt_layernorm` / `kwt_gelu` 均已逐位验证

## 1. 为什么不能"一个引擎打天下"

| 阶段 | IN_DIM | OUT_DIM | 权重类型 |
|---|---|---|---|
| Q/K/V 投影 | 64 | 64 | int4（静态） |
| QKᵀ | 64 | **100**（99 补到 4 的倍数） | **int8**（K 是运行时数据） |
| AV | **128**（99 补到 64×2） | 64 | **int8**（V 是运行时数据） |
| O 投影 | 64 | 64 | int4（静态） |

`kwt_gemm_engine` 的 `IN_DIM/OUT_DIM/WB` 是编译期参数，因此需要**三个实例**：

```
u_proj   : IN=64, OUT=64, WB=4    ← Q/K/V/O 分时复用（4 次）
u_score  : IN=64, OUT=100, WB=8   ← QKᵀ
u_av     : IN=128, OUT=64, WB=8   ← 概率加权
```

面积：3 × 256 MAC ≈ 0.9 mm²（上限 2.25 mm²，仍有余量）。

## 2. 数据流与缓冲

| 缓冲 | 大小 | 用途 |
|---|---|---|
| x_buf | 99×64 int8 = 6.2 KB | 层输入 |
| q_buf / k_buf / v_buf | 各 6.2 KB | 投影结果 |
| score_buf | 99×100 int16 = 19.4 KB | QKᵀ + 缩放 |
| p_buf | 99×100 int8 = 9.7 KB | softmax 概率 |
| ctx_buf | 99×64 int8 = 6.2 KB | 概率加权 |
| out_buf | 99×64 int8 = 6.2 KB | O 投影输出 |
| param_buf | 每层 ~40 KB | 本层 Q/K/V/O 权重 + bias + m |

合计约 **100 KB**，用 16b×4096 宏（8 KB）拼 13 个，面积约 0.13 mm²。

## 3. 控制序列

```
IDLE
 └─ x 已在 x_buf
 1. u_proj ← Wq/bq/mq, act←x_buf      → q_buf
 2. u_proj ← Wk/bk/mk, act←x_buf      → k_buf
 3. u_proj ← Wv/bv/mv, act←x_buf      → v_buf
 4. u_score ← wgt=k_buf（转置）, act=q_buf  → score_buf（int16）
 5. u_softmax ← score_buf（每行截到 99）    → p_buf
 6. u_av ← wgt=v_buf（补到 128 行）, act=p_buf（补 0） → ctx_buf
 7. u_proj ← Wo/bo/mo, act←ctx_buf    → out_buf
DONE
```

关键点：
- **K 必须转置后写入 u_score 的权重端口**（`score = Q·Kᵀ`）
- score 的 OUT_DIM 是 100，softmax 只用前 99 列
- AV 的 IN_DIM 补到 128，多出的 29 行/列填 0（权重与激活同时补 0，点积不受影响）

## 4. 周期估算（@150 MHz）

| 阶段 | 周期 | 说明 |
|---|---|---|
| Q/K/V 投影 | 3 × 19008 | 每次 99×16 组 × 3 周期/组 |
| QKᵀ | 99×25 组 × 3 = 7.4 K | OUT_DIM=100 |
| softmax | 99 × 298 = 29.5 K | 每行 4 遍扫描 |
| AV | 99×16 组 × 2 段 × 3 = 9.5 K | SEGS=2 |
| O 投影 | 19 K | |
| **每层合计** | **≈ 132 K 周期** | 0.88 ms @150 MHz |
| **12 层** | **≈ 1.58 M 周期** | **10.6 ms** |

> 瓶颈是 softmax（29.5 K）和三次投影（57 K）。
> 优化方向：softmax 合并遍历、投影之间流水。决赛前再优化。

## 5. 参数组织（每层）

```
param_buf 布局（int4，按输出通道优先）
  [0x0000] Q 权重 64×64    4096 nibble = 2 KB
  [0x0800] K 权重 64×64    2 KB
  [0x1000] V 权重 64×64    2 KB
  [0x1800] O 权重 64×64    2 KB
  [0x2000] Q 的 m_int 64×32b = 256 B
  [0x2100] K 的 m_int
  [0x2200] V 的 m_int
  [0x2300] O 的 m_int + bias_q
  ...
```

（最终布局在参数转换脚本里定稿，见 `doc/04_定点数值规范.md` §8）
